# rkgk to 3D

졸라맨이나 도형화한 스케치로 잡은 인물 구도를 3D 마네킹 포즈로 바꿔 주는 웹툴 (MVP).
웹에서는 카메라를 돌리고 간단히 보정한 뒤 이미지와 BVH를 내려받고, 손끝 같은 세부는 클립 스튜디오에서 조정한다.

## 실행

빌드 과정이 없는 정적 페이지다. 화면 절반에 그리고, 나머지 절반에서 3D로 확인한다. ES 모듈을 쓰므로 `file://`로는 열리지 않고 정적 서버가 필요하다.

```sh
python3 -m http.server 8000   # → http://localhost:8000
```

GitHub Pages 등에 그대로 올려도 된다. three.js, MediaPipe, fflate, Pretendard는 jsDelivr에서, 포즈 모델은 Google 저장소에서 불러온다.

## 사용법

화면 왼쪽 절반에 그리면 오른쪽 절반의 3D 마네킹이 바로 따라온다. 획을 하나 끝낼 때마다 바뀐 인물만 다시 인식한다.

**그리기 (왼쪽)**
- **색 = 인물:** 색마다 따로 레이어가 있고, 색 하나를 인물 한 명으로 인식한다 (최대 6명). 먼저 그리기 시작한 인물이 뒤, 나중에 그린 인물이 앞이다.
- **펜:** 펜 태블릿·스타일러스는 필압이 굵기에 반영된다. 마우스와 손가락은 일정한 굵기로 그린다.
- **지우개:** 지금 고른 색(인물)의 선만 지운다.
- **라쏘:** 감싼 부분을 떼어 내서 끌어 옮긴다. Delete로 지우고, Esc나 다른 곳 클릭으로 내려놓는다.
- **관절 보기:** 인식된 관절을 그림 위에 점선으로 겹쳐 보여 준다. 빨간 점은 신뢰도가 낮은 관절이다.
- 다른 인물에게 가려지는 팔다리도 그려야 한다. 생략하면 그 관절은 추측으로 채워진다.

| 단축키 | 동작 |
| --- | --- |
| Ctrl/⌘ + Z | 되돌리기 |
| Ctrl/⌘ + Shift + Z, Ctrl + Y | 다시 하기 |
| B · E · L | 펜 · 지우개 · 라쏘 |
| 1 ~ 6 | 색(인물) 고르기 |
| [ · ] | 굵기 줄이기 · 늘리기 |
| Esc | 라쏘 내려놓기, 선택 해제 |

**3D (오른쪽)**
- 왼쪽 드래그로 회전, 오른쪽 드래그로 이동, 휠로 줌. 카메라를 직접 움직이기 전까지는 그릴 때마다 모든 인물이 보이도록 맞춰지고, 맞추기 버튼을 누르면 다시 자동으로 맞춘다.
- 위쪽 칩이나 마네킹을 누르면 보정 카드가 열린다: 몸 앞뒤 반전, 팔다리별 앞뒤 뒤집기, 앞뒤 순서, 크기. 위치는 화살표를 끌어서 옮긴다. 인형의 밝은 쪽이 왼쪽이다.
- 아직 사람으로 인식되지 않은 색은 칩으로만 보이고 3D와 내보내기에서는 빠진다.
- PNG 저장: 현재 시점 그대로 (선택 표시·이름표 제외, 2배 해상도)
- 묶음 내보내기: `view.png` + `sketch.png` + 인물별 `NN_personN.bvh` + `camera.json` + 안내문을 ZIP으로 내려받는다.
- ⋯ 메뉴: 인식 모델, 신뢰도 기준, 바닥 격자, 카메라 수치

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/board.js` | 그리기 판: 인물별 레이어, 필압 펜, 지우개, 라쏘, 되돌리기, 관절 안내선 |
| `js/input.js` | 선 영역 찾기, 잘라내기, 실루엣 변환 |
| `js/pose.js` | MediaPipe Pose Landmarker 실행 (GPU 실패 시 CPU) |
| `js/mannequin.js` | Mixamo식 뼈대 마네킹, 관절 좌표 → 뼈 회전 계산 |
| `js/bvh.js` | 1프레임 BVH 내보내기 (cm, `mixamorig:` 이름, ZXY 회전) |
| `js/viewer.js` | three.js 장면, 카메라, 선택·이동, PNG 캡처, 카메라 수치 |
| `js/main.js` | 화면 연결, 인식 예약, 배치, 보정, 내보내기 |

### 포즈 추출

선 영역을 여백과 함께 잘라 원본 → 실루엣(선으로 둘러싸인 안쪽을 칠함) → 선을 두껍게 한 실루엣 순서로 인식해 보고, 주요 관절 신뢰도 평균이 가장 높은 결과를 쓴다.
월드 좌표(m)로 팔다리 방향과 몸통·머리 방향을 맞추고, 팔꿈치와 무릎은 굽는 방향에 맞춰 위팔·허벅지의 비틀림을 정한다.

### 배치

모든 인물에 같은 축척(m/px)을 쓰고 그림 속 엉덩이 위치로 놓는다. 가장 낮은 발이 바닥에 닿게 하고, 순서대로 0.6m씩 앞뒤 간격을 준다. 3D에서 옮기거나 크기를 바꾼 만큼은 다시 그려도 유지된다.

## 검증 메모 (구상 문서의 [조사-확인 필요] 1번)

합성한 테스트 스케치로 확인한 결과:

- 면으로 칠한 도형화 스케치: 바로 잘 잡힌다.
- 외곽선만 있는 도형화 스케치: 그대로는 인식되지 않지만, 실루엣으로 바꾸면 잡힌다. 다만 앞/뒤(좌우)가 뒤바뀌어 나오는 경우가 있어 "몸 방향 반전"이 필요하다.
- 선 하나로 된 졸라맨: 선을 두껍게 해도 인식되지 않는다. 우회로(이미지 생성 AI)가 필요한 경우다.

실제 손그림으로는 아직 테스트하지 않았다.

## 아직 안 된 것

- 우회로(스케치를 이미지 생성 AI로 사람 이미지로 바꾼 뒤 인식)는 넣지 않았다.
- 클튜에서 BVH가 데생 인형에 제대로 적용되는지, 여러 인물 배치가 유지되는지(구상 문서 3·4번)는 확인하지 못했다. three.js BVHLoader로 다시 읽어 위치가 일치하는 것만 확인했다.
- 웹에서 바꾼 인물 크기는 BVH에 담을 수 없다 (위치에만 반영, `camera.json`에 기록).
